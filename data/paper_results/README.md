# Published results (transcribed)

Values transcribed verbatim from the INDOP paper (MobiCom '27 submission,
Tables 1-4 and Section 5.4). They are the **only real-measurement numbers in
this repository**; every other figure input is either produced by the
pipeline from your own captures (`results/`) or by the synthetic simulator.

| File | Source |
|---|---|
| `table1_anchor_sweep.csv` | Table 1 — anchor window sweep, CBRS 3595 MHz |
| `table2_methods.csv` | Table 2 — method comparison, 20-min 100 ms capture |
| `table3_multinode.csv` | Table 3 — multi-node results, July 2026 |
| `table4_gmm_components.csv` | Table 4 — GMM components, 72 s anchor |
| `cyclostationary_peaks.csv` | Section 5.4 — SCF alpha-profile peaks |

Note: Table 3 Sagepoint GT is 19.1 % (Table 2 lists 19.0 %; the gap of
-1.4 pp is reported in both). Physics GT for non-Sagepoint nodes uses
approximate calibration constants.
